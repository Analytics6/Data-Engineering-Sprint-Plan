## Sprint Goals (one-liners)

1. **Sprint 1:** Explain Spark job lifecycle and solve common PySpark interview coding problems (joins, windows, Delta, performance).
2. **Sprint 2:** Solve medium SQL problems and sketch parameterized ADF pipelines with clear building-block vocabulary.
3. **Sprint 3:** Design production-grade ADF incremental + metadata-driven flows with security, monitoring, and a spoken case study.
4. **Sprint 4:** Architect a Fabric Lakehouse end-to-end, map ADF skills to Fabric, and pass two full mock interviews.

## Definition of Done (program-wide)

A day is **Done** when all are checked:

- [ ] Tutorial notebook completed
- [ ] Assignment notebook attempted without notes (then reviewed)
- [ ] 5 interview Q&A written (or spoken and bullet-noted)
- [ ] Standup entry filled in that sprint’s `daily-standup.md`
- [ ] Day card moved to Done on `board.md`

A sprint is **Done** when:

- [ ] All day backlog items Done
- [ ] Sprint mock completed (see sprint `review.md`)
- [ ] Sprint checklist in plan / review satisfied
- [ ] Retro filled; 1–3 actions carried into next sprint backlog

## Ceremonies (every sprint)

| Ceremony | When | What to do |
|----------|------|------------|
| **Planning** | Day 1 morning (15–20 min) | Confirm goal, capacity, risks; skim `backlog.md` + `board.md` |
| **Daily standup** | Start of each study block (5 min) | Yesterday / Today / Blockers → `daily-standup.md` |
| **Mid-sprint check** | Day 4 (Wed) (10 min) | On track for mock? Cut scope if behind (never skip mock) |
| **Review (demo)** | Last day (45–60 min mock) | Demo skills via mock; tick `review.md` |
| **Retro** | After review (10–15 min) | Start / Stop / Continue → `retro.md`; copy actions forward |

### Standup prompts

- **Yesterday:** What notebooks / skills did I ship?
- **Today:** Which day # and notebooks am I doing?
- **Blockers:** Concept stuck / env issue / time risk?

### Mid-sprint check prompts

- Am I ≥50% through the sprint backlog?
- Weakest topic so far — schedule a 30-min fix before mock day?
- Any day to compress (read + assign only) so mock still happens?
